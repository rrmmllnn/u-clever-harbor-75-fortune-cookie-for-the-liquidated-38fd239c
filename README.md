One fortune cookie line for a crypto trader who has just been liquidated —
written to be read at 3 a.m. with an empty wallet and a stubborn sense of
humour. The fortune is concrete and specific ($47 of Bitcoin, a stranger,
coffee, 3 a.m.) with one twist: the lost money comes back as coffee, and the
laugh is shared.

## The fortune

> Your $47 of Bitcoin will return as coffee from a stranger at 3 a.m., and you will laugh together.

19 words, 97 characters, one line.

## Run it

```sh
python3 main.py
# writes /output/entry.txt
```

Deterministic: every run writes the same bytes. No network, no dependencies,
no secrets.
